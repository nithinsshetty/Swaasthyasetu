# SwaasthyaSetu Complete Android Prototype

Open the `SwaasthyaSetu_Complete_Android_App` folder in Android Studio and run the `app` configuration.

This prototype contains seven connected portals: Patient, ASHA Worker, Doctor, Hospital Staff, Ambulance Driver, Pharmacy, and Government/Admin, plus emergency SOS, rural/offline workflows, referrals, vitals/risk assessment, follow-up, voice intake prototype, teleconsultation, AI medical-scribe prototype, prescriptions, pharmacy dispensing, hospital capacity/bed reservation, health vault, notifications/statuses, consent/audit concepts, and cross-portal demo state.

External production services such as real ABDM integration, real WebRTC, live dispatch infrastructure, and clinically validated AI are represented as prototype/simulated functionality.
